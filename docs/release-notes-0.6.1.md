# Sango 0.6.1 早期測試版

這次更新補上城池防守方針與更完整的偵察情報，也整理了出征、戰略地圖及音樂鑑賞的操作方式。

## 下載與安裝

- **Android**：下載 `Sango-0.6.1-android-debug.apk`，依系統提示允許瀏覽器或檔案管理員「安裝未知應用程式」，再開啟安裝。本次提供 debug 測試版。
- **Windows x64**：下載 `Sango-0.6.1-windows-x64.zip`，完整解壓縮後執行 `Sango.exe`。壓縮檔已包含 Java，不需另外安裝。

GitHub 自動提供的 `Source code (zip)` 是原始碼。要直接遊玩，請下載 APK 或 Windows ZIP 附件。

## 本次更新

- 我方城池可以設定「穩健」、「積極迎戰」或「固守城池」三種防守方針，敵軍來襲時會影響攻防與雙方傷亡。
- 電腦勢力會依兵力與周邊威脅調整防守方針，不會永遠維持同一種部署。
- 偵察結果改為各勢力分開保存，有效期為三個月並包含偵察當月。情報期間內顯示的是偵察當時的狀態，不會自動更新。
- 電腦勢力偵察時也要遵守道路、行動力與金錢成本，不會直接讀取其他勢力的即時情報。
- 出征戰術移到出征操作內選擇；單純運兵時不再顯示戰術選項。
- 戰略地圖資源列簡化為「金」與「糧」，玩法說明補充兩者由整個勢力共用。
- 全螢幕地圖可在空白處點兩下還原；點兩下城池仍只會選取城池。
- 進入音樂鑑賞時會從頭播放目前曲目，對同一首曲目點兩下也可重新播放。
- 補充設定內的玩法說明，讓主要共通規則能直接在遊戲中查閱。

## 存檔與讀取

0.6.0 存檔會在讀取時自動升級；升級前仍建議先備份存檔。

一般內政、偵察、運兵與出征操作不會立即存檔。想取消尚未保存的操作，可以讀取存檔，回到上次保存的狀態。建立新局、月份結算、手動存檔，以及從遊戲選單返回大廳或離開遊戲時，會保存進度。
