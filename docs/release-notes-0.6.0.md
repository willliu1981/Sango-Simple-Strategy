# Sango 0.6.0 測試版

Sango《簡易三國志》是一款回合制三國戰略遊戲。經營城池、維持軍糧與民心，調動部隊與各方勢力爭奪天下。

## 下載與安裝

- **Android**：下載 APK，依系統提示允許瀏覽器或檔案管理員「安裝未知應用程式」，再開啟安裝。本次提供 debug 測試版。
- **Windows x64**：下載 Windows ZIP，完整解壓縮後執行 `Sango.exe`。已內含 Java，無須另外安裝；請保留整個解壓後的資料夾。

GitHub 的 `Source code (zip)` 是原始碼。要直接遊玩，請選擇 APK 或 Windows ZIP 附件。

## 存檔與讀取

一般內政、偵察、運兵與出征操作不會立即存檔。想取消尚未保存的操作，可以讀取存檔，回到上次保存的狀態。

建立新局、月份結算、手動存檔，以及從遊戲選單返回大廳或離開遊戲時，都會保存進度。直接關閉視窗或強制關閉程式，不會保存尚未存檔的操作。

月份結算後，讀取同一槽無法回到結算前。想保留較早的進度，請先手動存到另一個槽位。

## 測試版說明

遊戲仍在調整中，可能遇到操作或戰鬥結果異常。遇到問題時，歡迎附上操作步驟、裝置型號與截圖回報。更新前建議先備份存檔。
