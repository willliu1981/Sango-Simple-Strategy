# Sango 0.6.0 接續工作

使用者已明確 `!exec`；這次實作基準為上傳的 Sango-source(1).zip，不是聊天中舊的 0.5.2 交付包。

已寫入：總民心 AP 表（首月 3，後續最多 9）、玩家 AI 共用扣點、徵兵 slider／數字輸入、人口根號上限及至少保留 2000、單次 10000 硬上限、按兵力加權新兵素質、部分兵力訓練及小數保存、年度人口、四季 BGM 播放器、兩秒 crossfade、音樂鑑賞。四季 MP3 與圖資刻意未納入 source。詳見 rules／UPGRADE／VALIDATION，不以本摘要代替公式。

初版數值：本城／全勢力民心 60/40，新兵訓練 50，士氣 30～70，年度 −4/−2/0/+2/+4%，年度變化 −3000～+5000，年度負成長底線 1000；徵兵保留人口 2000，floor(10√P)，每兵 0.5 金／0.5 糧向上取整；覆蓋 20000、受訓部分各 +5。城市容量選擇保留舊初始人口、給各城約 1.5 倍容量的草案；這些不是自然平衡驗收後永久鎖定的數值。

GameState schema 5、Save document schema 1。原版真實 schema 4 fixture 已由 Repository 遷移測試通過；舊六城不自動擴成全國。當月 AP 保留，讀檔不補點。玩家存檔不在 Source ZIP 中。降版需要升級前備份。

播放器預期春1～3《春風入城》、夏4～6《炎日運籌》、秋7～9《暮秋望陣》、冬10～12《寒夜圖謀》四首本機 MP3，但音檔不隨 source 提供。音樂鑑賞從 Lobby 或 Settings 進入；退出回實際上下文。未做新旋律、收尾、無縫 loop 或響度正規化。

目前驗證僅 JDK21 --release17 + 本機 SimpleUI 內嵌 GDX1.12.1 的離線編譯／六組回歸，以及封裝套用核對。正式設定仍 GDX1.13.1。四季 MP3 未隨 source 提供，因此無法將音訊解碼結果視為這份提交的驗收。Gradle8.8下載DNS失敗，無 Desktop／Android／OpenAL／實際 UI 驗收。不要把靜態／假 Music 測試稱為 Runtime 通過。

下一步先讓使用者套用 Patch，在本機跑 :core:check、:lwjgl3:run，回報徵兵 modal、人口資訊、播放器文字／排版、平台 pause/resume 與實際換季音樂。若要續改，先取得當時最新本機 Source 或具體錯誤；不能假設已套用、已 Commit。

仍未做真實武將、安民／民心恢復、更大野戰軍、多支軍隊、自然遊玩難度平衡、音樂進度拖拉與解鎖。野戰軍仍最多1000、每勢力一支，和徵兵10000硬上限分開。AI用相同成本但不是完整玩家策略集合。歷史戰報無上限等已知成長成本保留。

交付沒有自行 Commit。Source ZIP不附字型、font atlas及含字型的本機SimpleUI JAR；新副本由 prepare-local-assets-0.6.0.ps1 從原專案補，Patch更新不需補資產。不得回傳字型檔。
