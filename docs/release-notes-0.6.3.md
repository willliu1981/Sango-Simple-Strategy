## 下載與安裝

發布附件時請使用以下名稱；目前文件不表示附件已上傳：

- Android：`Sango-0.6.3-android-debug.apk`。允許下載所用 App「安裝未知應用程式」後安裝，一般側載不需要開發者模式。這仍是 debug 簽章測試包。
- Windows x64：`Sango-0.6.3-windows-x64.zip`。完整解壓後執行 `Sango.exe`；打包時內含 Java runtime。

GitHub 的 Source code ZIP 是原始碼，不是可直接啟動的遊戲。
