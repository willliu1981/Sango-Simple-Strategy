# Sango 0.6.2 早期測試版

這次更新整理情報、內政與戰報介面，讓偵察結果與勢力資源更容易查閱。

實際遊玩影片：[觀看《簡易三國志》遊戲過程](https://youtu.be/RraldBojNZg)

## 下載與安裝

- **Android**：下載 `Sango-0.6.2-android-debug.apk`，依系統提示允許瀏覽器或檔案管理員「安裝未知應用程式」，再開啟安裝。本次提供 debug 測試版。
- **Windows x64**：下載 `Sango-0.6.2-windows-x64.zip`，完整解壓縮後執行 `Sango.exe`。壓縮檔已包含 Java，不需另外安裝。

GitHub 自動提供的 `Source code (zip)` 是原始碼。要直接遊玩，請下載 APK 或 Windows ZIP 附件。

## 本次更新

- 偵察成功後，敵城資訊會直接顯示偵察當時的防守方針；情報到期前可作為出征戰術的參考。
- 點擊已掌握情報的敵方勢力名稱，可查看依偵察快照估算的總金、總糧、總兵力與下月行動力。未掌握的城市與行軍部隊不會納入估算。
- 內政頁新增勢力共用的金、糧顯示；徵兵確認前會列出花費後的剩餘金、糧，方便調整徵兵數量。
- 內政按鈕統一為「操作｜費用」格式；徵兵不再在按鈕上重複顯示限制與預覽資訊。
- 天下戰報會列出最新月份的全部戰事，同月我方參與的戰鬥優先顯示；城池入口仍只顯示該城最近一次戰報。
- 修正城池情報文字重疊，以及未讀戰事提示延續到下一月份的問題。

## 存檔與讀取

0.6.1 存檔可直接讀取，不需要轉換。一般內政、偵察、運兵與出征不會立即存檔；想取消尚未保存的操作，可讀取存檔回到上次保存狀態。建立新局、月份結算、手動存檔，以及從遊戲選單返回大廳或離開遊戲時，會保存進度。
