# Sango 0.5.1 實作規則與公式

這份文件描述此 Source 的程式規則，不是史實模型。整數值除法皆向下取整；`clamp(value, minimum, maximum)` 表示限制上下界。`MilitaryRules` 使用 long 中間乘積，最後才取整並限制到 int 範圍。

## 全國劇本

新局 `warlords_china` 使用 `china_42`：42 城、68 條雙向道路，每條道路行軍一個月。整體代表遊戲化的漢末全國戰略範圍，包含遼東、河北、西涼、關中、中原、荊州、益州、江東、南中與嶺南／交趾等區域；不模擬所有縣邑，也不宣稱精確歷史疆界。

| 可選勢力 | 初始領地（首都在前） | 十二月目標 |
|---|---|---|
| 曹操 | 陳留、許昌 | 汝南 |
| 劉備 | 平原、北海 | 鄴 |
| 孫策 | 吳郡、會稽 | 廣陵 |
| 袁紹 | 鄴、南皮 | 上黨 |
| 劉表 | 襄陽、江陵 | 江夏 |
| 馬騰 | 武威、安定 | 天水 |

黃巾佔汝南、壽春，其餘為中立；二者不計入可選的六勢力。未被玩家選取的五個勢力與黃巾皆由 AI 控制。固定所有權不隨玩家選擇而重排。

每個月玩家共用 3 行動力，並非每城 3 點。每個勢力同時至多一支野戰軍。玩家出征留下至少 400 守軍，派出 400～1000 人、以 100 人為單位；消耗 1 行動力及 100 糧。

AI 初次集結為 4 月，之後每 3 月評估一次。每個 AI 選己方前線與相鄰非己方目標，留下至少 300 守軍、派 400～700 人，支付 100 糧。兵力不足時按徵兵成本補充，人口與士氣同步扣除，不再免費加兵。中立勢力不主動出兵。這是簡單 AI，沒有外交或戰略規劃器；未做完整難度平衡。

## 士氣

城市守軍與野戰軍各自保存 `morale`，合法範圍 0～100，與民心 `publicOrder` 不同。

| 命令 | 原有成本／效果 | 新版士氣效果 |
|---|---|---|
| 徵兵 | 1 行動力、100 金、100 糧；人口 −200、兵力 +200 | −5，最低 0 |
| 訓練 | 1 行動力、50 金；訓練 +5 | +5，最高 100 |

訓練值滿但士氣未滿仍可執行訓練；兩者都滿時不允許浪費資源。徵兵不另外降低訓練值。沒有被動每月士氣恢復，也未加入戰後勝負士氣增減。

出征時 `army.morale = originCity.morale`，不重新從民心推算；零士氣仍可出征，只是戰力較弱。攻陷城市後，倖存部隊的訓練與士氣成為新駐軍數值。增援與敗退回原城合併時按實際兵力加權：

`合併士氣 = floor((原兵力 × 原士氣 + 加入兵力 × 加入士氣) / 總兵力)`

訓練值以同一加權方法處理。

## 攻守戰力

`訓練倍率 = (100 + 訓練) / 100`

`士氣倍率 = (150 + 士氣) / 200 = 0.75 + 士氣 / 200`

`城防倍率 = (100 + floor(城防 / 2)) / 100`

| 士氣 | 倍率 |
|---:|---:|
| 0 | 0.75 |
| 50 | 1.00 |
| 80 | 1.15 |
| 100 | 1.25 |

| 戰術 | 戰力倍率 | 攻方傷亡倍率 |
|---|---:|---:|
| 穩健 BALANCED | 1.00 | 1.00 |
| 強攻 ASSAULT | 1.20 | 1.25 |
| 保守 CAUTIOUS | 0.85 | 0.75 |

`攻方戰力 = floor(兵力 × 訓練倍率 × 士氣倍率 × 戰術倍率)`

`守方戰力 = floor(兵力 × 訓練倍率 × 士氣倍率 × 城防倍率)`

實作把乘積放在分子、最後一次除法，不在每個中間倍率做整數除法。兵力大於零時最小戰力為 1；零守軍則為 0 並走無抵抗佔領。攻方戰力大於或等於守方即攻方勝利。

例：雙方各 1000 人、訓練 50。攻方穩健、士氣 80，戰力 `1725`；守方士氣 50、城防 40，戰力 `1800`，守方勝。

城防 100 提供 1.50 倍守軍戰力；奇數城防沿用既有整數除法，例如 40 與 41 都是 1.20 倍，42 才是 1.21 倍。

## 有守軍的傷亡與佔領

以計算完成的攻守戰力計算百分比：

`攻方基礎傷亡% = clamp(floor(守方戰力 × 50 / 攻方戰力), 15, 80)`

`攻方實際傷亡% = clamp(floor(攻方基礎傷亡% × 戰術傷亡百分比 / 100), 10, 90)`

`守方傷亡% = clamp(floor(攻方戰力 × 60 / 守方戰力), 20, 95)`

`傷亡人數 = floor(原兵力 × 傷亡% / 100)`

城防提高守方戰力，所以會同時影響勝負與這些傷亡率。強攻不是單純優勢，它提高戰力也提高自身傷亡。極少數兵力的整數取整可能產生 0 傷亡；不再為了最低值憑空造出或扣除士兵。

攻陷有守軍的城池：城防 −10、民心 −10，最低 0。攻方倖存者成為駐軍；敗方倖存守軍視為潰散離開戰場，不自動變成攻方兵力。戰報的「守方生還」不等於仍留在城中的守軍。

## 空城無抵抗佔領

「空城」專指抵達時 `targetCity.troops == 0`，不是只看是否中立，也不是城防為零。敵對勢力的零守軍城與中立零守軍城使用相同規則。

攻守雙方戰鬥傷亡都是 0；所有權改為攻方、到達部隊全數轉為駐軍。城防與民心各 −5、最低 0。保存 `UNOPPOSED_OCCUPATION` 紀錄，支援未讀與已讀，不播放交鋒音效。城防再高也不會自行產生守軍或攻方最低傷亡。

出征糧與每月軍糧仍然支付。月底軍糧結算早於行軍與佔領，因此缺糧可能先逃兵；「零戰鬥傷亡」不是免除後勤損失。

## 治水與季節經濟

公式未因全國地圖而改動。

`六月洪災機率% = clamp(65 − 治水, 5, 60)`

`發生洪災時秋收損失% = clamp(45 − floor(治水 / 2), 10, 40)`

| 治水 | 六月洪災機率 | 洪災發生時秋收損失 |
|---:|---:|---:|
| 0 | 60% | 40% |
| 20 | 45% | 35% |
| 40 | 25% | 25% |
| 60 | 5% | 15% |
| 70 | 5% | 10% |
| 100 | 5% | 10% |

洪災發生時農業 −3、民心 −5、人口 −200，並調整當年秋收倍率。治水命令消耗 80 金與 1 行動力，治水 +5。農業與商業開發不立即產生糧或金。

`三、六、九、十二月商稅 = 80 + 商業 × 6 + floor(人口 / 2000)`

`九月基礎秋收 = 500 + 農業 × 20 + floor(人口 / 100)`

`實際秋收 = floor(基礎秋收 × harvestModifierPercent / 100)`

`每月軍糧 = ceil((勢力城內駐軍 + 野戰軍總數) / 20)`

月末順序：軍糧與逃兵 → 洪災 → 商稅 → 秋收 → 行軍與戰鬥／佔領 → AI → 日期與期限更新。

## 任務與可操作狀態

`ScenarioObjectiveStatus` 與 `GameplayStatus` 分離。達標或期限／首都條件失敗後，仍能內政、攻打敵軍、佔領空城、存檔與推進月份。達標結果不會因下一場戰鬥失敗而重設。

首都失守但仍有其他城市，遷都並繼續；完全失去領地時才 `ELIMINATED`，行動力歸零，該勢力在途部隊解散，避免同月又佔城復活。未加入流亡勢力玩法。

## 地圖、資料與效能界線

地圖世界座標為 4200 × 2800 的節點畫布；相機只影響 UI，不修改 GameState。總覽縮成城名，拉近顯示勢力／目標／未讀戰事。拖曳超過門檻或雙指操作會取消節點點擊，繪圖與觸控都裁切在地圖區域。

城池數 C、道路數 E、戰報數 B：地圖未讀數先彙整為約 O(B + C)；道路定位仍以線性節點查找，約 O(E × C)，42 城／68 路規模可接受。AI 每次檢查各勢力城市的道路與目標，也使用線性查找，不是大規模路徑規劃。戰報未設上限，copy-on-write 與 JSON 保存會隨歷史 B 增長；這是長期瓶頸，不宣稱支援無限戰報或數百城。
